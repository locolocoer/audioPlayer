# 飞鱼音乐 (FeiYu Music)

一款基于 Electron 的桌面音乐播放器，支持 WebDAV 云端与本地文件夹两种音乐源，内置完整的播放、歌词、封面、收藏、播放列表与统计体系。

当前版本：**v1.3.4**（详见 [CHANGELOG](./CHANGELOG.md)）

---

## ✨ 功能特性

### 音乐源与扫描
- WebDAV 服务器连接管理（地址/用户名/密码/端口、测试连接、多源并存）
- 本地文件夹扫描，支持 `file://` 直接播放
- 递归扫描 mp3/flac/wav/ogg/aac/m4a 等格式
- 增量同步：未变化文件跳过、缺失标签自动补全、已删除文件自动清理
- 本地文件夹自动监控，文件变更自动增量重扫
- 跨源去重合并：同一首歌多源/多格式只显示一行，可在详情中切换来源

### 音乐库
- 音乐库视图：歌曲 / 专辑 / 歌手 / 文件夹 多维度浏览
- 搜索、筛选（来源）、排序（歌名/歌手/专辑/时长/播放次数/最近播放）
- 虚拟滚动：万级曲库流畅滚动
- 多选批量操作：批量加入播放列表、批量收藏、批量编辑元数据
- 歌手批量改名（右键歌手项）、重复曲目检测
- 收藏、最近播放、播放统计

### 播放器
- 播放/暂停/上一首/下一首、进度拖拽、音量调节
- 播放模式：顺序 / 随机 / 单曲循环 / 心动模式（按播放频率加权收藏）
- 倍速兼容、FLAC 解码失败自动 FFmpeg 转码兜底
- 睡眠定时器（15/30/45/60/90 分钟）
- 队列面板：查看/跳转/移除/拖拽排序
- 断点续播：重启恢复上次歌曲与位置

### 歌词与封面
- 内嵌封面（ID3 APIC）提取展示；无内嵌则显示占位
- 歌词：内嵌 USLT/SYLT、外部 `.lrc` 文件
- 桌面歌词：独立透明置顶窗口，卡拉OK 逐字高亮，支持字号/颜色/背景/对齐设置
- 歌词样式设置（播放页字号/对齐）

### 播放列表
- 多个命名播放列表，支持新建/重命名/删除/切换
- 列表内拖拽排序，独立持久化

### 音效
- 10 段图形均衡器（Web Audio），内置预设 + 自定义预设保存/覆盖/删除
- 音频可视化频谱

### 系统集成
- 系统托盘控制、全局媒体键、键盘快捷键（空格/方向键/Ctrl+方向键等）
- 桌面歌词窗口、迷你播放窗口（独立小窗）
- 窗口尺寸记忆、设置全记忆（主题/强调色/音量/均衡器/歌词/扫描设置等）

### 数据管理
- 缓存管理界面（占用大小、逐文件清理）
- 数据库备份导出
- 本地 MP3 编辑元数据时写回文件标签（node-id3）

### 趣味玩法
- 听歌统计：累计播放/时长、歌曲/歌手/专辑排行、近 30 天播放趋势
- 随机专辑冒险：一键随机整张专辑播放
- 心情电台：专注 / 放松 / 高能 / 沉浸 四档自动选歌
- 播放页皮肤换装：默认 / 磁带 / 唱片机 / 霓虹复古（深浅主题自适应）

## 🚀 安装与运行

```bash
# 安装依赖
npm install

# 开发模式（热更新）
npm run dev

# 生产构建
npm run build

# 启动已构建产物（不重建）
npm start

# 打包安装程序（Windows）
npm run package
```

> 提示：`npm start` 直接启动现有 `out/` 产物，不会重建；改代码后先 `npm run build`。

## 📖 快速开始

1. **添加音乐源**：打开「设置」→ 添加 WebDAV 服务器（填地址/端口/账号/密码）或「添加本地文件夹」
2. **扫描**：在音乐源列表点击「扫描」，等待扫描完成（支持取消）
3. **播放**：在音乐库点任意歌曲开始播放；支持搜索、排序、专辑/歌手/文件夹浏览
4. **歌词**：有内嵌或同目录 `.lrc` 的歌曲自动显示歌词；播放栏音符按钮可开启桌面歌词
5. **收藏/列表**：右键歌曲加入收藏或播放列表；音乐库头部可批量操作

## 📁 目录结构

```
audioPlayer/
├── src/
│   ├── main/           # Electron 主进程（IPC/扫描/数据库/WebDAV/转码）
│   ├── preload/        # 预加载脚本（安全暴露 API）
│   └── renderer/       # React 渲染进程
│       ├── components/ # 组件（播放栏/队列/桌面歌词/均衡器/可视化...）
│       ├── pages/      # 页面（音乐库/播放/收藏/播放列表/最近/统计/设置）
│       ├── stores/     # zustand 状态
│       └── utils/      # 工具（LRC 解析等）
├── resources/          # 图标、ffmpeg
├── docs/               # 需求/自测/工作流状态
├── out/                # 构建产物
└── electron.vite.config.ts
```

## ⚙️ 数据与设置

- 数据库与设置存储于系统 userData 目录：`%APPDATA%\feiyu-music\`（已通过 `app.setName` 统一，各启动方式共享）
- 音频临时缓存位于系统临时目录 `audioplayer-cache/`，可在设置页查看与清理
- 播放记录（播放次数/最近播放/趋势）从 v0.7.0 起持续累积
