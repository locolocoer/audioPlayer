# AudioPlayer — 需求文档 v0.1.0

## 项目概述

基于 Electron 的桌面音乐播放器，支持连接 WebDAV 服务器播放云端音乐。自动扫描 WebDAV 上的音频文件，将元数据缓存在本地 SQLite 数据库中，后续启动时直接读取缓存，避免重复扫描。

## 技术选型

| 层 | 选型 | 说明 |
|----|------|------|
| 桌面框架 | Electron 28+ | 跨平台桌面应用 |
| 前端框架 | React 18 + TypeScript | 渲染进程 UI |
| 构建工具 | Vite (electron-vite) | 快速HMR开发 |
| WebDAV客户端 | `webdav` npm | WebDAV协议操作 |
| ID3解析 | `music-metadata` npm | 音频元数据提取 |
| 本地数据库 | `better-sqlite3` | SQLite本地缓存 |
| 打包 | `electron-builder` | 多平台打包 |

## 非功能性需求

- NF001: 支持 Windows / macOS / Linux 三平台
- NF002: 启动速度 < 3秒（含缓存加载）
- NF003: 内存占用 < 200MB（含1000首歌曲缓存）
- NF004: 支持中文/英文界面
